Sifr is aiming for a practical balance: Python-like ergonomics with tight,
predictable performance characteristics.

The alpha preview focuses on:

- Core runtime stability
- Better tooling for iterative development
- Faster startup and tighter feedback loops

This post is intentionally short, but it establishes the release-note format
for future milestones.
